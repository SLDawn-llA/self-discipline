# 一点 · 每天向前一点

为安卓手机设计的自律网页，也可在电脑使用。默认六件小事、每天完成三项就算达标，不要求把任务全部做完。没有账号，没有后台，不向外部服务发送任务和打卡内容。

在线使用：**[打开一点](https://sldawn-lla.github.io/self-discipline/)**。安卓 Chrome 打开后，在菜单选择“添加到主屏幕”或“安装应用”。首次在线打开并完成缓存后，可以离线使用。

## 执行版：帮助开始，再逐步形成成果

首页现在优先显示“一件主线”：最低版与标准版分开，一键 5 分钟启动；卡住时可以 2 分钟重启。计时结束不会自动算完成，需要如实写下成果或尝试。近 7 天行动日、具体成果和下一步，比连续天数更突出。

在“今日”或“任务”点 **查看起步包**，即可预览并启用算法岗实习的 7 天起步计划。包含 LeetCode、八股 / 基础问题口述、项目表达和岗位准备，附第 3、5、7 天成果截止点。启用时可以选择暂停旧任务；旧任务和历史记录保留。任务名称、最低动作、标准完成条件、开始情境、时长、星期与链接都可自行修改。

“我的”可调整近 7 天主线行动目标和奖励，管理小截止点、生成行动报告。报告只记录自报事实，需要你自行复制发送。没有后台推送；建议用手机闹钟提醒固定开始动作。

旧版备份可以导入，会自动迁移到新版。默认六项日常任务仍保留为旧用户和通用模式的起点；每日完成项数属于辅助统计，主线最低版与标准完成不会混算。

## 现在使用

1. 双击本文件夹里的 **启动一点.bat**，保持窗口打开。当前电脑已有 Node.js，无需安装依赖。
2. 在电脑浏览器打开 **http://localhost:5188**。
3. 手机和电脑连接同一个 Wi-Fi，在安卓 Chrome 中输入启动窗口显示的“手机访问”地址，例如 `http://192.168.1.10:5188`。如 Windows 弹出网络提示，允许可信的专用网络即可。

也可以在终端运行 `node serve.js`（无需 npm）。端口被占用时运行 `node serve.js --port 5189`。局域网访问需要电脑开机、服务运行；手机用 `localhost` 会指向手机本身，务必使用窗口里的 WLAN / Wi-Fi 地址。VPN、访客 Wi-Fi、无线客户端隔离或防火墙可能影响连接。

## 日常怎么用

- **今日**：点击任务右侧方框完成或撤销；可以筛选待完成任务，写每日感想，回看以前的日期。
- **任务**：添加、编辑、删除任务；选择每天、工作日、周末或指定星期；支持暂停和上下调整顺序。时间只是安排提示，不会发送系统通知。
- **足迹**：日历区分已经开始、最低版与标准完成；点日期可以查看或补记录。页面展示近 7 天开始日、主线行动日、累计标准完成项数，以及每轮实际成果和卡点。
- **我的**：修改称呼、每日目标、计划开始时间与长度；导出或导入 JSON 备份。

修改任务、删除任务、调整目标只更新今天和未来；过去已经记录的任务、任务名称和当天目标保持原样。暂停或删除会从今天清单中移除该任务（包括今天对它的打卡），过去记录保留。重新启用后可以重新打卡。

新增任务从创建当天开始，按指定星期出现。没有记录的过去日期保持留白，不会把今天的新任务补进过去。每日目标超过当天任务数时，以当天任务数为准；没有任务的日子不计作达标。100 天只是默认计划周期，结束后可以继续打卡。

## 在手机上独立使用 / 安装到桌面

这是一个准备好安装的 PWA：包含应用清单、图标和离线缓存。把应用文件放到支持 **HTTPS** 的静态网站空间后，用安卓 Chrome 打开，浏览器菜单选择“添加到主屏幕”或“安装应用”。首次在线打开并完成缓存后，可以离线打卡，不依赖电脑开机。电脑 `localhost` 也支持安装和离线。

**局域网 HTTP 模式可在线使用和保存记录，但无法启用 Service Worker 离线缓存；Chrome 是否允许添加快捷方式取决于浏览器。** 文件夹中直接双击 HTML 可作简单预览，建议使用上面的服务来保证存储与资源加载一致。本项目提供网页 / PWA，没有原生 APK。

发布时只需上传：`index.html`、`styles.css`、`core.js`、`execution.js`、`app.js`、`sw.js`、`manifest.webmanifest`、`icons/`。不需要上传测试、启动器、截图、备份或本地服务文件；支持站点根目录和子目录。

GitHub Pages 使用本仓库 `main` 分支的根目录。提交发布文件后，GitHub 自动更新网站；在仓库 Actions 中可查看部署结果。

## 数据与备份

数据存储在当前网址、当前浏览器的 `localStorage`，不会自动同步到其他设备。**手机与电脑、不同浏览器、HTTP 与 HTTPS、不同网址或端口是独立数据空间。** 从局域网地址迁移到正式网址前，先在原地址导出备份，再到新地址导入。

换手机、换网址、清理浏览器数据或卸载应用前，请导出备份。导入会要求确认，再替换现有数据；格式验证失败不会覆盖已有数据。存储失败时会在页面显示提示，可以导出内存中的暂存记录。建议不用无痕模式，并定期备份。

## 开发与验证

纯 HTML / CSS / JavaScript，无构建过程或线上第三方资源。运行 `node --test tests/core.test.cjs` 检查日期、重复安排、目标、历史快照、统计及导入验证。npm 正常可用时也可以用 `npm start` / `npm test`。服务仅暴露应用资源，不能通过 HTTP 读取备份、测试或此文件夹中的其他文件。

可选浏览器测试使用已有 Playwright 和 Chrome：`node tests/browser.cjs` 验证原有功能；`node tests/execution-browser.cjs` 验证启动、暂停恢复、成果分级、截止点、次日计划、离线计时等新流程。`PLAYWRIGHT_MODULE` 可指向本机已安装的 Playwright，不是运行应用的依赖。

修改发布资源后应更新 `sw.js` 中的缓存版本，以便清理旧版缓存。当前使用在线优先、缓存回退策略，离线时读取已缓存的应用。
